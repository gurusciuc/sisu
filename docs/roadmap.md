# Roadmap

1. Resolve CEF extension tab/window identity and action/panel ownership. Exercise uBOL lifecycle/settings and Proton workflows with a dedicated test account.
2. Complete ordinary multi-tab restore, multi-window coordination, popup handling, crash recovery, downloads and permission UX.
3. Port the proven shell to macOS and Linux. Validate X11, Wayland, accessibility, scaling, keyboard, clipboard and IME natively.
4. Complete native cosmetics, controlled replacements and verified list updates. Audit privacy partitioning, fingerprint exposure and network routes.
5. Expand matched release-build workloads and long sessions. Tune leaks, caches and lifetimes before introducing optional protected-work discarding.
6. Harden, review dependencies/notices and enable signed versioned packages and authenticated updates.

The project has a working Windows feasibility preview. Stage-specific exit gates are in docs/plan-alignment.md.
